## 🎯 Purpose & Problem Statement

### Why It Exists
Understanding the foundation of the web begins with mastering semantic markup and standard CSS before adopting heavy frontend frameworks. This assignment challenges the developer to build a multi-page personal portfolio highlighting projects, professional skills, and contact pathways using pure vanilla web standards.

### What It Solves & Demonstrates
- **Semantic HTML5 Outline:** Employs appropriate semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) to improve accessibility (a11y) and search engine optimization (SEO).
- **Responsive Multi-Device Layouts:** Uses media queries, CSS Grid, and Flexbox to guarantee fluid responsiveness across smartphones, tablets, and desktop displays.
- **Modular Stylesheet Architecture:** Separates styles into modular CSS files (`style.css`, `index.css`, `about.css`, `contact.css`, `projects.css`) for clean maintainability.

---

## 📂 Multi-Page Architecture

- **`index.html` (Home / Hero):** Introduces the developer, displays professional headlines, and showcases featured projects (e.g. Narsingdi Biggan Club, Birthday Wish app).
- **`about.html` (Profile & Background):** Details educational achievements, engineering philosophies, and technical competencies across web and cloud technologies.
- **`contact.html` (Communication Hub):** Interactive contact form and social media communication links.
- **`css/` Directory:** Modular cascading stylesheets managing typography, layout grids, animations, and media breakpoints.

---

## 🛠️ Tech Stack & Dependencies

- **Markup:** HTML5 (Semantic specifications)
- **Styling:** CSS3 (Flexbox, CSS Grid, Media Queries, Custom CSS Variables)
- **Assets:** Web-optimized project screenshots and iconography
- **Dependencies:** Zero external libraries or runtime frameworks

## 🚀 Getting Started

### Prerequisites
- Any modern web browser (Google Chrome, Firefox, Microsoft Edge, Safari).

### Viewing Locally

```bash
# 1. Clone the repository
git clone https://github.com/shawkath646/academic-portfolio-assignment-01.git
cd academic-portfolio-assignment-01

# 2. Open index.html directly in your default browser
# On Windows:
start index.html
# On macOS:
open index.html
# On Linux:
xdg-open index.html

# Or serve with a lightweight HTTP server:
python -m http.server 3000
# Visit http://localhost:3000
```
